Put your OpenRouter key on this computer.

You need a free OpenRouter account. openrouter is a service that connects AI models to websites like this one. This page picks the best AI model for you automatically from the ones that are curently avalable, free, and reasonably fast at responding.

Go to openrouter.ai and sign in, you can do this with your school google account. Open Settings, then Keys, then click Create a new key. Give it a name such as Class analyser. Copy the key (it starts with sk-or-) and paste it below. this is the key that this website will send to OpenRouter in order to identify you. You only need to do this once.

Openrouter has both free and paid models, the free modles are curently of comparible intelligence to the ones avalable through the free plans for chat GPT or Google Gemini, although they will respond slower.

How to use this

download the pupil progress reports for the class by going to the screen where you select a class to view, press the 3 dots and chppse download, then follow the emails you revece from pupil progress, it may take some muinites to arive

Press the select folder button on the first page and choose the zipped folder of Pupil Progress as it was downloaded. This page reads each report and reconstructs the class spreadhseet from each pupil's file, once it is finished it wll automaticaly take you to the next page, you can optionaly include a blank coppy of any asessment this class has sat, in order to give the AI more information about what those papers were about

press go, this website will find the best free and avalable AI to analyse it, you will see the model's internal thinking as it analyses the data, then it will write a report for the class.

Why this is safe

This website never sends a pupil’s name or identifyable information to an AI. this website uses your own computer to read the reports conventially, it stips the data of any identifyable information: every name (including the techer's), Unique Pupil Number, date of birth and contact detail is taken out before anything leaves the machine.

What the model receives is a table of random codes such as P07, together with grades and topic names and year group, this website is a method of sending this tool to your computer easily, without needing to install anything on your device, it is a web app that runs in your browser, no information ever leaves. i made this website personaly, and can confirm that it not a security risk itself.

The code to name key stays on your computer. When the model answers, this page swaps the codes back to names on your computer so you can read the report without needing to constantly check. You can read the exact outgoing message in full on the page before you press Go. If a name or a Unique Pupil Number is still in that text, the page will refuse to send it.

other services like google docs will save responses to the cloud, making them accessible if you use more than one computer, this tool does not do this, no information ever leaves this computer under any circumstances, past reports will be saved on this computer only, if you delete one it will be immediately gone forever

If this page breaks later

This website should be self sufficient for a reasonable amount of time. It is meant to keep working on its own, on the teacher’s computer, without anyone having to look after it day to day.

At some point OpenRouter or Pupil Progress will inevitablly change the format of something in a way that breaks this website. That is a normal risk with a tool that takes input from someone else’s PDFs and talks to someone else’s AI for whitch we hav no control over.
